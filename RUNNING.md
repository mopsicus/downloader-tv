# 📱 Запуск приложения в Android Studio

## 🚀 Быстрый старт

### 1️⃣ Открытие проекта
1. Запустите **Android Studio**
2. Выберите **File → Open**
3. Откройте папку `/Users/mopsicus/Projects/downloader-tv`
4. Дождитесь синхронизации Gradle (может занять 1-2 минуты)

### 2️⃣ Создание эмулятора (если нет)

#### Для обычного Android телефона:
1. Откройте **Tools → Device Manager** (или кнопка 📱 в правом верхнем углу)
2. Нажмите **Create Device**
3. Выберите устройство (например, **Pixel 6**)
4. Выберите системный образ (рекомендуется **API 34** - Android 14)
5. Нажмите **Finish**

#### Для Android TV:
1. Откройте **Tools → Device Manager**
2. Нажмите **Create Device**
3. Перейдите на вкладку **TV**
4. Выберите **Android TV (1080p)** или **Android TV (4K)**
5. Выберите системный образ (рекомендуется **API 34**)
6. Нажмите **Finish**

### 3️⃣ Запуск приложения

#### Способ 1: Через меню конфигураций
1. В верхней панели найдите выпадающее меню с конфигурациями
2. Выберите одну из:
   - **app** - выбор устройства вручную
   - **app (Emulator)** - автоматический выбор эмулятора
3. Выберите нужный эмулятор из списка
4. Нажмите кнопку **▶️ Run** (зеленый треугольник) или `Shift + F10`

#### Способ 2: Через контекстное меню
1. Правой кнопкой мыши на `app` в структуре проекта
2. Выберите **Run 'app'**

#### Способ 3: Debug режим
1. Нажмите кнопку **🐛 Debug** или `Shift + F9`
2. Запустится приложение с возможностью отладки

### 4️⃣ Первый запуск
- ⏱️ Первый запуск может занять 2-3 минуты (загрузка эмулятора)
- 📦 Gradle соберет APK автоматически
- 📲 APK установится на эмулятор
- 🚀 Приложение запустится автоматически

## 🎮 Управление в эмуляторе

### На телефоне:
- **Мышь** - клики по кнопкам
- **Клавиатура** - навигация стрелками (если focus работает)

### На Android TV:
- **Клавиши стрелок** ← ↑ → ↓ - навигация D-pad
- **Enter** - нажатие кнопки
- **ESC** - назад
- **Alt + Enter** - переключение полноэкранного режима эмулятора

## 🔧 Полезные команды

### Gradle через терминал:
```bash
# Сборка
./gradlew assembleDebug

# Установка на эмулятор/устройство
./gradlew installDebug

# Очистка
./gradlew clean

# Запуск на эмуляторе
adb shell am start -n com.mopsicus.downloadertv/.MainActivity
```

### Просмотр логов:
```bash
# Все логи приложения
adb logcat | grep "DownloaderTV"

# Очистка логов
adb logcat -c
```

## 🐛 Решение проблем

### Проблема: Эмулятор не запускается
**Решение:**
1. Включите виртуализацию в BIOS (Intel VT-x / AMD-V)
2. macOS: проверьте права в **Security & Privacy**
3. Попробуйте создать новый эмулятор

### Проблема: Gradle sync failed
**Решение:**
1. **File → Invalidate Caches... → Invalidate and Restart**
2. Проверьте интернет соединение
3. **Tools → SDK Manager** - установите все нужные компоненты

### Проблема: Приложение не устанавливается
**Решение:**
1. Удалите старую версию: `adb uninstall com.mopsicus.downloadertv`
2. Очистите проект: **Build → Clean Project**
3. Пересоберите: **Build → Rebuild Project**

### Проблема: Нет интернета в эмуляторе
**Решение:**
1. Перезапустите эмулятор
2. Проверьте настройки сети эмулятора
3. Cold Boot: **Device Manager → Cold Boot Now**
